# IPCA Gestão Académica — Node.js + MongoDB

## Instalação

```bash
npm install
```

## Popular a base de dados (primeira vez)

```bash
node seed.js
```

## Iniciar o servidor

```bash
node app.js
```

Acede em: http://localhost:3000
